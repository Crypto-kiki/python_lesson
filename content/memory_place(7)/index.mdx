# 추억 장소 아카이브 만들기 7편 (최종편)

<a href="https://python-lesson-red.vercel.app/blogs/memory_place(6)" target="_blank">이전 교안 보기</a>

지난 6편에서는 **카카오맵 전국지도에 저장된 모든 장소를 마커로 표시하는 기능**을 완성했습니다.

즉 지금 프로젝트는 아래 상태까지 와 있습니다.

* 장소 등록 / 수정 / 삭제
* 카카오 장소 검색 자동입력
* 작성자(author) 연결
* 웹 CRUD
* DRF CRUD
* 로그인 / 권한 처리
* 메인페이지 전국지도 표시
* 전체 장소 보기 페이지 전국지도 표시
* 모든 장소 마커 표시

이제 마지막으로 필요한 것은,
**전체 장소 보기** 에서 한 걸음 더 나아가
**내가 기록한 장소만 모아서 관리하는 화면** 을 만드는 것입니다.

실제 사용자 입장에서 가장 자주 보게 될 화면은 이런 화면입니다.

> “내가 저장한 장소만 다시 보고 싶다.”
>
> “추천해둔 장소만 따로 보고 싶다.”
>
> “검색해서 예전에 갔던 장소를 빨리 찾고 싶다.”

그래서 이번 최종편에서는,
6편에서 만든 전국지도 코드를 그대로 재활용하면서 아래를 한 번에 완성하겠습니다.

* 마이페이지 만들기
* 로그인한 사용자의 장소만 조회하기
* 내 장소만 전국지도에 마커 표시하기
* 검색 기능 붙이기
* 지역 / 추천 여부 필터 붙이기
* 검색 / 필터 결과를 지도와 카드 목록에 동시에 반영하기
* 결과가 없을 때 empty state UI 만들기

즉 이번 편이 끝나면,
추억 장소 아카이브 프로젝트는 **지도 기반 개인 아카이브 서비스** 로 마무리됩니다.

# 0. 이번 편 전체 흐름 먼저 보기

## 이번 편 실습 순서

1. 왜 마이페이지가 필요한지 이해하기
2. URL 추가하기
3. 6편의 `views.py` 흐름을 유지하면서 `MyPageView` 추가하기
4. 현재 로그인한 사용자의 장소만 가져오기
5. 검색 / 필터 적용하기

9. 디버깅 포인트 확인하기
10. 최종 체크리스트 확인하기

이번 편 핵심은,
**6편 코드 구조를 최대한 유지하면서 필요한 것만 확장** 하는 것입니다.

즉 이미 잘 돌아가던 코드 스타일을 갑자기 크게 바꾸지 않고,
그 위에 `MyPageView` 와 `my_page.html` 만 자연스럽게 얹는 방식으로 진행하겠습니다.

# 1. 왜 마지막에 마이페이지를 만들까요?

6편에서는 “전체 유저의 모든 장소” 를 전국지도에서 볼 수 있게 만들었습니다.

이 기능은 서비스가 풍성해 보이게 해주고,
지도 위에 마커가 많이 찍히는 재미도 있습니다.

하지만 실제 서비스에서는 사용자가 더 자주 보는 화면이 따로 있습니다.
바로 **내 기록만 다시 보는 화면** 입니다.

예를 들어 이런 요구가 많습니다.

* 내가 저장한 장소만 다시 보고 싶다.
* 추천해둔 장소만 모아보고 싶다.
* 서울에 있는 내 장소만 골라보고 싶다.
* 예전에 기록한 특정 장소를 검색해서 다시 찾고 싶다.

이걸 만족시키려면,
이제는 전체 목록과는 별도로 **개인화된 마이페이지** 가 필요합니다.

그리고 이번 편에서 검색 / 필터까지 붙이면,
프로젝트가 단순 CRUD 예제를 넘어 **서비스다운 흐름** 을 갖추게 됩니다.

# 2. `places/urls.py` 에 마이페이지 URL 추가하기

6편 흐름을 그대로 이어서,
마이페이지 URL 하나만 추가하겠습니다.

```python title="places/urls.py"
from django.urls import path

from .views import (
    HomeView,
    MyPageView,
    PlaceCreateView,
    PlaceDeleteView,
    PlaceDetailView,
    PlaceListView,
    PlaceUpdateView,
    signup,
)

app_name = 'places'

urlpatterns = [
    path('', HomeView.as_view(), name='home'),
    path('signup/', signup, name='signup'),
    path('places/', PlaceListView.as_view(), name='place_list'),
    path('places/create/', PlaceCreateView.as_view(), name='place_create'),
    path('places/<int:pk>/', PlaceDetailView.as_view(), name='place_detail'),
    path('places/<int:pk>/update/', PlaceUpdateView.as_view(), name='place_update'),
    path('places/<int:pk>/delete/', PlaceDeleteView.as_view(), name='place_delete'),
    path('mypage/', MyPageView.as_view(), name='my_page'),
]
```

## 왜 `signup` 도 함수형 그대로 가져가나요?

6편 완성본에서는 `signup` 을 함수형 뷰로 사용하고 있었습니다.

이번 7편에서는 6편 코드를 그대로 이어가는 것이 목적이므로,
회원가입 부분을 새 클래스로 바꾸지 않고 **기존 방식 그대로 유지** 하는 것이 더 자연스럽습니다.

즉 이번 편은 **필요한 부분만 확장하고, 기존 흐름은 흔들지 않는 것** 이 중요합니다.

> 아래 MyPageView를 아직 추가 안한상태라 여기 까지만 입력하시면 오류가 발생하는건 자연스럽습니다.

# 3. `places/views.py` 에 `MyPageView` 추가하기

이제 6편의 `views.py` 흐름을 유지한 상태에서,
맨 아래에 `MyPageView` 를 추가하겠습니다.

이번에는 6편 코드와 정확히 이어지도록 아래 사항을 맞췄습니다.

* `signup` 은 함수형 그대로 유지
* `AuthorRequiredMixin` 메시지 문구와 redirect 방식 유지
* `PlaceCreateView`, `PlaceUpdateView` 의 `page_title`, `submit_label`, `kakao_javascript_key` 패턴 유지
* `PlaceDetailView.get_queryset()` 의 `select_related('author')` 패턴 유지
* 전체 지도용 `map_places` 만드는 방식도 6편과 같은 스타일로 유지

아래는 **7편 최종 반영 버전** 입니다.

```python title="places/views.py"
from django.conf import settings
from django.contrib import messages
from django.contrib.auth import login
from django.contrib.auth.mixins import LoginRequiredMixin, UserPassesTestMixin
from django.db.models import Q
from django.shortcuts import redirect, render
from django.urls import reverse_lazy
from django.views.generic import CreateView, DeleteView, DetailView, ListView, TemplateView, UpdateView

from .forms import PlaceForm, SignUpForm
from .models import Place


class HomeView(TemplateView):
    template_name = 'places/home.html'

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        featured_places = Place.objects.filter(is_featured=True)[:3]
        latest_places = Place.objects.select_related('author').all()[:6]
        map_places = Place.objects.exclude(latitude__isnull=True).exclude(longitude__isnull=True)

        context['featured_places'] = featured_places
        context['latest_places'] = latest_places
        context['kakao_javascript_key'] = settings.KAKAO_JAVASCRIPT_KEY
        context['map_places'] = [
            {
                'id': place.id,
                'title': place.title,
                'region': place.region or '지역 정보 없음',
                'address': place.address or '주소 정보 없음',
                'latitude': float(place.latitude),
                'longitude': float(place.longitude),
            }
            for place in map_places
        ]
        return context


class PlaceListView(ListView):
    model = Place
    template_name = 'places/place_list.html'
    context_object_name = 'places'
    paginate_by = 6

    def get_base_queryset(self):
        return Place.objects.select_related('author').all().order_by('-created_at')

    def get_queryset(self):
        queryset = self.get_base_queryset()

        q = self.request.GET.get('q', '').strip()
        region = self.request.GET.get('region', '').strip()
        featured = self.request.GET.get('featured', '').strip()

        if q:
            queryset = queryset.filter(
                Q(title__icontains=q)
                | Q(address__icontains=q)
                | Q(region__icontains=q)
                | Q(memory_line__icontains=q)
                | Q(author__username__icontains=q)
            )

        if region:
            queryset = queryset.filter(region=region)

        if featured == 'true':
            queryset = queryset.filter(is_featured=True)
        elif featured == 'false':
            queryset = queryset.filter(is_featured=False)

        return queryset

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)

        base_queryset = self.get_base_queryset()
        filtered_queryset = self.get_queryset()
        map_places = filtered_queryset.exclude(latitude__isnull=True).exclude(longitude__isnull=True)
        region_options = (
            base_queryset.exclude(region__isnull=True)
            .exclude(region='')
            .values_list('region', flat=True)
            .distinct()
        )

        context['kakao_javascript_key'] = settings.KAKAO_JAVASCRIPT_KEY
        context['map_places'] = [
            {
                'id': place.id,
                'title': place.title,
                'region': place.region or '지역 정보 없음',
                'address': place.address or '주소 정보 없음',
                'latitude': float(place.latitude),
                'longitude': float(place.longitude),
            }
            for place in map_places
        ]
        context['total_count'] = base_queryset.count()
        context['featured_count'] = base_queryset.filter(is_featured=True).count()
        context['filtered_count'] = filtered_queryset.count()
        context['region_options'] = sorted(region_options)
        context['search_keyword'] = self.request.GET.get('q', '').strip()
        context['selected_region'] = self.request.GET.get('region', '').strip()
        context['selected_featured'] = self.request.GET.get('featured', '').strip()
        return context


class PlaceDetailView(DetailView):
    model = Place
    template_name = 'places/place_detail.html'
    context_object_name = 'place'

    def get_queryset(self):
        return Place.objects.select_related('author').all()


class PlaceCreateView(LoginRequiredMixin, CreateView):
    model = Place
    form_class = PlaceForm
    template_name = 'places/place_form.html'

    def form_valid(self, form):
        form.instance.author = self.request.user
        messages.success(self.request, '새로운 추억 장소가 등록되었습니다.')
        return super().form_valid(form)

    def get_success_url(self):
        return reverse_lazy('places:place_detail', kwargs={'pk': self.object.pk})

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        context['page_title'] = '장소 기록 추가'
        context['submit_label'] = '장소 저장하기'
        context['kakao_javascript_key'] = settings.KAKAO_JAVASCRIPT_KEY
        return context


class AuthorRequiredMixin(UserPassesTestMixin):
    def test_func(self):
        place = self.get_object()
        return place.author == self.request.user

    def handle_no_permission(self):
        messages.error(self.request, '본인 글만 수정하거나 삭제할 수 있습니다.')
        return redirect('places:place_list')


class PlaceUpdateView(LoginRequiredMixin, AuthorRequiredMixin, UpdateView):
    model = Place
    form_class = PlaceForm
    template_name = 'places/place_form.html'
    context_object_name = 'place'

    def form_valid(self, form):
        form.instance.author = self.request.user
        messages.success(self.request, '추억 장소가 수정되었습니다.')
        return super().form_valid(form)

    def get_success_url(self):
        return reverse_lazy('places:place_detail', kwargs={'pk': self.object.pk})

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        context['page_title'] = '장소 기록 수정'
        context['submit_label'] = '수정 내용 저장하기'
        context['kakao_javascript_key'] = settings.KAKAO_JAVASCRIPT_KEY
        return context


class PlaceDeleteView(LoginRequiredMixin, AuthorRequiredMixin, DeleteView):
    model = Place
    template_name = 'places/place_confirm_delete.html'
    context_object_name = 'place'
    success_url = reverse_lazy('places:place_list')

    def delete(self, request, *args, **kwargs):
        messages.success(self.request, '추억 장소가 삭제되었습니다.')
        return super().delete(request, *args, **kwargs)


class MyPageView(LoginRequiredMixin, ListView):
    model = Place
    template_name = 'places/my_page.html'
    context_object_name = 'places'
    paginate_by = 6

    def get_base_queryset(self):

        if q:
            queryset = queryset.filter(
                Q(title__icontains=q)
                | Q(address__icontains=q)
                | Q(region__icontains=q)
                | Q(memory_line__icontains=q)
            )

        if region:
            queryset = queryset.filter(region=region)

        if featured == 'true':
            queryset = queryset.filter(is_featured=True)
        elif featured == 'false':
            queryset = queryset.filter(is_featured=False)

        return queryset

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)

        base_queryset = self.get_base_queryset()
        filtered_queryset = self.get_queryset()
        map_places = filtered_queryset.exclude(latitude__isnull=True).exclude(longitude__isnull=True)
        region_options = (
            base_queryset.exclude(region__isnull=True)
            .exclude(region='')
            .values_list('region', flat=True)
            .distinct()
        )

        context['kakao_javascript_key'] = settings.KAKAO_JAVASCRIPT_KEY
        context['map_places'] = [
            {
                'id': place.id,
                'title': place.title,
                'region': place.region or '지역 정보 없음',
                'address': place.address or '주소 정보 없음',
                'latitude': float(place.latitude),
                'longitude': float(place.longitude),
            }
            for place in map_places
        ]
        context['total_count'] = base_queryset.count()
        context['featured_count'] = base_queryset.filter(is_featured=True).count()
        context['filtered_count'] = filtered_queryset.count()
        context['region_options'] = sorted(region_options)
        context['search_keyword'] = self.request.GET.get('q', '').strip()
        context['selected_region'] = self.request.GET.get('region', '').strip()
        context['selected_featured'] = self.request.GET.get('featured', '').strip()
        return context


def signup(request):
    if request.user.is_authenticated:
        return redirect('places:home')

    if request.method == 'POST':
        form = SignUpForm(request.POST)
        if form.is_valid():
            user = form.save()
            login(request, user)
            messages.success(request, '회원가입이 완료되었습니다. 바로 로그인되었습니다.')
            return redirect('places:home')
    else:
        form = SignUpForm()

    return render(request, 'registration/signup.html', {'form': form})
```

## 3-1. 왜 검색 대상을 `memory_line` 으로 맞췄나요?

6편 완성본의 템플릿 흐름을 보면 카드에서 핵심 요약 문장으로 사용하던 필드는 `memory_line` 이었습니다.

즉, 검색도 `memory_line` 기준으로 맞추는 편이 더 자연스럽습니다.

그래서 이번 수정본에서는 검색 대상을 아래처럼 정리했습니다.

* `title`
* `address`
* `region`
* `memory_line`

## 3-2. 왜 `MyPageView` 만 새로 추가하면 되나요?

이미 6편까지에서 아래 구조는 다 완성되어 있었습니다.

* 장소 모델
* 로그인 사용자
* 작성자(author) 연결
* 지도용 좌표 데이터
* 카드형 템플릿 패턴

즉 이번 편은 프로젝트를 새로 만드는 것이 아니라,
**기존 구조 위에 “내 것만 보기” 화면을 하나 더 얹는 작업** 입니다.

그래서 핵심은 기존 코드를 갈아엎는 것이 아니라,
**현재 로그인한 사용자 기준 QuerySet** 을 잘 만드는 것입니다.

```html title="templates/base.html"
{% load static %}
```

## 5-3. 왜 `place_list.html` 과 비슷하게 만들었나요?

이유는 단순합니다.

6편에서 이미 전체 장소 보기 페이지가 아래 구조로 완성돼 있었기 때문입니다.

* 상단 소개 영역
* 지도 패널
* 카드 그리드
* 빈 상태 카드

```python title="places/utils.py"
from django.db.models import Q

REGION_ALIASES = {
    '서울': ['서울', '서울특별시', '서울시'],
    '부산': ['부산', '부산광역시', '부산시', '부산 중구'],
    '강릉': ['강릉', '강릉시', '강원 강릉시'],
    '태안': ['태안', '태안군', '충남 태안군'],
    '제주': ['제주', '제주시', '제주특별자치도', '제주도'],
    '인천': ['인천', '인천광역시', '인천시'],
    '대구': ['대구', '대구광역시', '대구시'],
    '대전': ['대전', '대전광역시', '대전시'],
    '광주': ['광주', '광주광역시', '광주시'],
    '울산': ['울산', '울산광역시', '울산시'],
    '세종': ['세종', '세종시', '세종특별자치시'],
}


def normalize_region(region: str) -> str:
    if not region:
        return ''

    cleaned = region.strip()

    for standard_name, aliases in REGION_ALIASES.items():
        if cleaned in aliases:
            return standard_name

    return cleaned


def get_region_filter_q(selected_region: str) -> Q:
    normalized = normalize_region(selected_region)

    if not normalized:
        return Q()

    aliases = REGION_ALIASES.get(normalized, [normalized])

    query = Q()
    for alias in aliases:
        query |= Q(region__iexact=alias.strip())

    return query


def get_normalized_region_options(region_values):
    normalized_set = {
        normalize_region(region)
        for region in region_values
        if region and region.strip()
    }
    return sorted(normalized_set)
```

```
카드 목록은 이 queryset 으로 렌더링
↓
같은 queryset 에서 좌표 있는 데이터만 추려 map_places 생성
↓
지도 마커도 같은 결과를 기반으로 표시
```

즉 카드 따로, 지도 따로가 아니라
**한 번 필터링된 결과를 두 방식으로 보여주는 구조** 입니다.

이 구조를 잘 이해해두면,
나중에 다른 프로젝트에서도 목록 + 지도, 목록 + 차트, 목록 + 달력 연동을 만들 때 훨씬 쉬워집니다.

# 8. 자주 발생하는 오류와 디버깅 포인트

## 8-1. 검색이 안 돼요

확인할 것:

* `from django.db.models import Q` 를 추가했는지
* `memory_line` 필드명이 실제 모델과 일치하는지
* 템플릿의 input `name="q"` 가 맞는지

---

## 8-2. 지역 필터 옵션이 안 보여요

확인할 것:

* 저장된 장소의 `region` 값이 실제로 있는지
* `region=''` 또는 `NULL` 값만 있는 것은 아닌지
* `region_options` 컨텍스트가 전달되는지

---

## 8-3. 카드 목록은 보이는데 지도에는 아무것도 안 나와요

확인할 것:

* 해당 장소들에 `latitude`, `longitude` 값이 있는지
* 검색 / 필터 결과가 0건이 아닌지
* 카카오 자바스크립트 키가 정상인지

이번 구현에서는 좌표가 없는 장소는 지도에서 제외됩니다.

즉 카드 목록은 보여도,
지도에는 안 나올 수 있습니다.

---

## 8-4. 마커 클릭 시 상세 페이지로 이동하지 않아요

확인할 것:

```javascript
window.location.href = `/places/${place.id}/`;
```

이 경로가 현재 URL 구조와 맞는지 확인하세요.

---

## 8-5. 페이지네이션을 넘기면 검색 조건이 사라져요

페이지네이션 링크에 아래 QueryString 이 같이 붙어 있어야 합니다.

```html
&q={{ search_keyword }}&region={{ selected_region }}&featured={{ selected_featured }}
```

이 부분이 없으면 다음 페이지에서 조건이 초기화됩니다.
